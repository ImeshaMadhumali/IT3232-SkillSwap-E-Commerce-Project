# IT3232-SkillSwap-E-Commerce-Project

## 🌟 SkillSwap - A Skill Sharing Platform
SkillSwap is a peer-to-peer skill-sharing e-commerce platform that allows users to exchange and offer skills using a unique points or payment-based system.

### 🗝️Deliverables:
 🎗️A web-based platform (React.js frontend, Spring Boot backend, MongoDB database)<br>
 🎗️User authentication system<br>
 🎗️Secure chat and negotiation system<br>
 🎗️Points-based skill exchange system<br>
 🎗️Payment gateway for direct transactions<br>
 🎗️Review and rating mechanism<br>
 🎗️Admin dashboard for moderation and analytics<br>

### 📍 Beneficiaries:
1. Freelancers: Gain access to skills without financial constraints<br>
2. Students & Learners: Exchange knowledge with experienced professionals<br>
3. Small Business Owners: Obtain services without upfront payment<br>
4. Educators & Mentors: Provide guidance and receive skill-based compensation<br>

### 🏷️ Related Projects:
👩‍💻 Fiverr & Upwork: Focus solely on paid freelance services. SkillSwap sharing platform incorporates skill-trading and a points system.
👩‍💻 Coursera & Udemy: Provide learning resources but lack direct peer-to-peer skill exchange.
 
#### 🧰 Tech Stack
🎨 Frontend: React.js<br>
🕹️ Backend: Spring Boot, RESTful APIs<br>
🪢 Database: MySQL<br>
🎯 Auth: JWT<br>
🔗 Real-Time: WebSockets (chat)<br>
